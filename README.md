# Bank Management System

A web-based bank management system developed as student coursework using **Java EE** and **MySQL**.

## Overview

The application uses Java Servlets to handle web requests, JSP for page rendering, and JDBC for database access. It runs on Apache Tomcat and uses Maven to manage dependencies and build the project.

## Technology Stack

| Component | Technology |
| --- | --- |
| Programming language | Java |
| Database | MySQL |
| Database access | JDBC |
| Servlet API | Java Servlet 4.0 |
| View templates | JSP |
| Frontend | HTML, CSS |
| Servlet container | Apache Tomcat |
| Build tool | Maven |
